# プロジェクト アーキテクチャ

## ファイル・フォルダ命名

| 対象                           | パス                                                        | 規約                                  |
| ------------------------------ | ----------------------------------------------------------- | ------------------------------------- |
| file                           | `src/**/*.{ts,tsx}`                                         | `KEBAB_CASE`                          |
| folder                         | `src/!(app)/**/`                                            | `KEBAB_CASE`                          |
| App Router                     | `src/app/**/`                                               | `NEXT_JS_APP_ROUTER_CASE`             |
| feature                        | `src/features/{feature}`                                    | `auth`, Supabase table name           |
| queries                        | `src/features/{feature}/queries/*.ts`                       | `server`, `client`, `admin` / `{api}` |
| configs, schemas, types, utils | `src/features/{feature}/{configs,schemas,types,utils}/*.ts` | `{feature}`                           |
| hooks                          | `src/features/{feature}/hooks/use-*.ts`                     | `use-*.ts`                            |

## import

書き方:

| 対象             | パス                                 | 規約                                                     |
| ---------------- | ------------------------------------ | -------------------------------------------------------- |
| import           | `src/**/*.{ts,tsx}`                  | `./` か `@/` で書く。`../` は書けない                    |
| namespace import | `@/features/**` からの `import * as` | 名前は `@/features/` より後ろの path を camelCase にする |
| 並び順           | `src/**/*.{ts,tsx}`                  | import と export を並べ替える。`eslint --fix` で直る     |

依存方向:

| 層                 | パス                                              | import してよい app 内部                                                                |
| ------------------ | ------------------------------------------------- | --------------------------------------------------------------------------------------- |
| lib                | `src/lib/**/*.ts`                                 | `./`                                                                                    |
| utils              | `src/utils/*.ts`                                  | `./`                                                                                    |
| queries            | `src/features/*/queries/*.ts`                     | file 名に対応する `@/lib` だけ (`queries/garage.ts` は `@/lib/garage`)                  |
| services           | `src/features/*/services/*.ts`                    | `@/features/*/queries`, `@/features/*/schemas`, `@/features/*/types`, `@/utils`         |
| loaders            | `src/features/*/loaders/*.ts`                     | `@/features/*/services`                                                                 |
| actions            | `src/features/*/actions/*.ts`                     | `@/features/*/services`                                                                 |
| hooks              | `src/features/*/hooks/*.ts`                       | `@/components/ui`, `@/features/*/actions`, `@/features/*/loaders`, `@/features/*/types` |
| feature components | `src/features/*/components/*.tsx`                 | `@/components`, `@/features/*/hooks`                                                    |
| app                | `src/app/**/*.{ts,tsx}`                           | `@/components`, `@/utils`, `@/features/*/components`, `@/features/*/loaders`            |
| configs            | `src/configs/*.ts`, `src/features/*/configs/*.ts` | `@/features/*/types`                                                                    |
| schemas            | `src/features/*/schemas/*.ts`                     | -                                                                                       |
| types              | `src/features/*/types/*.ts`                       | `@/lib/*/types`, `@/lib/*/database`, `@/utils/mapping`                                  |
| feature utils      | `src/features/*/utils/*.ts`                       | `@/utils`, `@/features/*/utils`                                                         |

`@/configs` と `@/features/*/configs` は、queries を除くどの層からも import できる。configs は値の定義だけで、実行時に他の層へ依存しないため。configs が import できるのは types だけで、値を型で縛るために使う (`satisfies`, `Record<Union, string>`)。

queries は configs も utils も import できない。queries は汎用的な問い合わせだけを書き、件数や範囲などの値は services が決めて引数で渡す。

`@/features/*/types` は、features の層と app から import できる。型は compile で消えて、実行時の依存を作らないため。lib, utils, schemas は import できない。lib と utils は feature を知らない層で、schemas は types の元になるため。

hooks は `@/components/ui` だけ import できる。shadcn/ui 由来の file は外部 package と同じ扱いにする (`toast` など)。他の `@/components` は import できない。

`@/features/*/utils` は、queries を除く features の層と app から import できる。通信しない純粋な関数だけを置くため。

lib と utils の使い分け:

- 外部の service と通信するものは lib に置く (supabase, garage, stripe など)。lib を import できるのは queries だけなので、外部との通信は必ず queries を通る
- 通信しないものは utils に置く (mapping, cn, font, json-ld など)

## directive

| 層      | パス                          | 規約                         |
| ------- | ----------------------------- | ---------------------------- |
| actions | `src/features/*/actions/*.ts` | 先頭に `"use server"` が必須 |
| loaders | `src/features/*/loaders/*.ts` | `"use server"` は書けない    |
| hooks   | `src/features/*/hooks/*.ts`   | 先頭に `"use client"` が必須 |

## scope

| 対象                       | パス                                             | 規約                                           |
| -------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| services, loaders, actions | `src/features/*/{services,loaders,actions}/*.ts` | file 名は `server`, `client`, `admin` のどれか |

file 名は、動く場所と権限を表す。

| file 名  | 動く場所 | 権限         |
| -------- | -------- | ------------ |
| `client` | browser  | user 本人    |
| `server` | server   | user 本人    |
| `admin`  | server   | 何でもできる |

import できる下の層の file:

| file        | `client.ts` | `server.ts` | `admin.ts` |
| ----------- | ----------- | ----------- | ---------- |
| `client.ts` | o           | x           | x          |
| `server.ts` | x           | o           | x          |
| `admin.ts`  | x           | o           | o          |

- `client.ts` の行と列が x なのは、browser の file と server の file を混ぜないため
- `server.ts` が `admin.ts` を import できないのは、admin を使う処理を `admin.ts` だけに集めるため
- queries の `garage.ts` のように、`client` でも `admin` でもない file は `server.ts` の列として扱う
- hooks は `client.ts` の行として扱う。ただし actions は `"use server"` なので、どの file でも import できる

## error

| 対象     | パス                         | 規約                     |
| -------- | ---------------------------- | ------------------------ |
| features | `src/features/**/*.{ts,tsx}` | `try / catch` は書けない |

失敗の扱いは 2 通りだけにする。

- code で名指しできる失敗は、自分で書いた message を `return` する。message はそのまま画面に出る
- 名指しできない失敗は、`throw` のまま流す。画面は `error.tsx`、記録は `instrumentation.ts` が受け持つ

## tailwindcss

| 対象       | パス                | 規約                                          |
| ---------- | ------------------- | --------------------------------------------- |
| class の順 | `src/**/*.{ts,tsx}` | class を並べ替える。`eslint --fix` で直る     |

Tailwind の設定は `src/app/globals.css` から読む。path は lint を実行した directory から解決するので、`eslint` は pj の root で実行する。

## ディレクトリ構成

Root:

```txt
src/
  app/
  components/             # global components
    providers/
      theme-provider.tsx
    ui/                   # shadcn/ui
  configs/                # global config
  features/
  hooks/                  # global hooks
  lib/
  utils/                  # global utils
    cn.ts
    font.ts
    json-ld.ts
    mapping.ts
  instrumentation.ts
  proxy.ts
tests/
```

features:

```txt
src/features/{feature}/
  components/
    providers/{feature}-provider.tsx
  loaders/
  actions/
  configs/{feature}.ts
  hooks/use-*.ts
  services/
  schemas/{feature}.ts
  types/{feature}.ts
  utils/{feature}.ts
  queries/
```

lib:

```txt
src/lib/{api}/
  index.ts

src/lib/supabase/
  admin.ts
  client.ts
  database.ts
  proxy.ts
  server.ts
  types.ts
```
