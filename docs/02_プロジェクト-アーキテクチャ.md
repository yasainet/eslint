# プロジェクト アーキテクチャ

## ファイル・フォルダ命名

| 対象                  | パス                                        | 規約                                                                                                           |
| --------------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| ファイル              | `src/**/*.{ts,tsx}`                         | `KEBAB_CASE`                                                                                                   |
| フォルダ              | `src/!(app)/**/`                            | `KEBAB_CASE`                                                                                                   |
| App Router            | `src/app/**/`                               | `NEXT_JS_APP_ROUTER_CASE`                                                                                      |
| feature               | `src/features/{feature}`                    | `auth`, Supabase table name                                                                                    |
| queries               | `src/features/*/queries/*.ts`               | `src/lib` から決まる名前。supabase は `server`, `client`, `admin`。他は `index.ts` を持つ folder 名 (`garage`) |
| schemas, types, utils | `src/features/*/{schemas,types,utils}/*.ts` | feature の名前 (`features/users` なら `types/users.ts`, `utils/users.ts`)                                      |

## import

書き方:

| 対象             | パス                                 | 規約                                                     |
| ---------------- | ------------------------------------ | -------------------------------------------------------- |
| import           | `src/**/*.{ts,tsx}`                  | `./` か `@/` で書く。`../` は書けない                    |
| namespace import | `@/features/**` からの `import * as` | 名前は `@/features/` より後ろの path を camelCase にする |

依存方向:

| 層                 | パス                              | import してよい app 内部                                                                |
| ------------------ | --------------------------------- | --------------------------------------------------------------------------------------- |
| lib                | `src/lib/**/*.ts`                 | `./`                                                                                    |
| utils              | `src/utils/*.ts`                  | `./`                                                                                    |
| queries            | `src/features/*/queries/*.ts`     | file 名に対応する `@/lib` だけ (`queries/garage.ts` は `@/lib/garage`)                  |
| services           | `src/features/*/services/*.ts`    | `@/features/*/queries`, `@/features/*/schemas`, `@/features/*/types`, `@/utils/mapping` |
| loaders            | `src/features/*/loaders/*.ts`     | `@/features/*/services`                                                                 |
| actions            | `src/features/*/actions/*.ts`     | `@/features/*/services`                                                                 |
| hooks              | `src/features/*/hooks/*.ts`       | `@/features/*/actions`, `@/features/*/loaders`, `@/features/*/types`                    |
| feature components | `src/features/*/components/*.tsx` | `@/components`, `@/features/*/hooks`                                                    |
| app                | `src/app/**/*.{ts,tsx}`           | `@/components`, `@/utils`, `@/features/*/components`, `@/features/*/loaders`            |
| schemas            | `src/features/*/schemas/*.ts`     | -                                                                                       |
| types              | `src/features/*/types/*.ts`       | `@/lib/*/types`, `@/utils/mapping`                                                      |

lib と utils の使い分け:

- 外部の service と通信するものは lib に置く (supabase, garage, stripe など)。lib を import できるのは queries だけなので、外部との通信は必ず queries を通る
- 通信しないものは utils に置く (mapping, cn, font, json-ld など)

## directive

| 層      | パス                          | 規約                         |
| ------- | ----------------------------- | ---------------------------- |
| actions | `src/features/*/actions/*.ts` | 先頭に `"use server"` が必須 |
| loaders | `src/features/*/loaders/*.ts` | `"use server"` は書けない    |
| hooks   | `src/features/*/hooks/*.ts`   | 先頭に `"use client"` が必須 |

## scope

| 対象                       | パス                                             | 規約                                           |
| -------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| services, loaders, actions | `src/features/*/{services,loaders,actions}/*.ts` | file 名は `server`, `client`, `admin` のどれか |

file 名は、動く場所と権限を表す。

| file 名  | 動く場所 | 権限         |
| -------- | -------- | ------------ |
| `client` | browser  | user 本人    |
| `server` | server   | user 本人    |
| `admin`  | server   | 何でもできる |

import できる下の層の file:

| file        | `client.ts` | `server.ts` | `admin.ts` |
| ----------- | ----------- | ----------- | ---------- |
| `client.ts` | o           | x           | x          |
| `server.ts` | x           | o           | x          |
| `admin.ts`  | x           | o           | o          |

- `client.ts` の行と列が x なのは、browser の file と server の file を混ぜないため
- `server.ts` が `admin.ts` を import できないのは、admin を使う処理を `admin.ts` だけに集めるため
- queries の `garage.ts` のように、`client` でも `admin` でもない file は `server.ts` の列として扱う
- hooks は `client.ts` の行として扱う。ただし actions は `"use server"` なので、どの file でも import できる

## error

| 対象     | パス                         | 規約                     |
| -------- | ---------------------------- | ------------------------ |
| features | `src/features/**/*.{ts,tsx}` | `try / catch` は書けない |

失敗の扱いは 2 通りだけにする。

- code で名指しできる失敗は、自分で書いた message を `return` する。message はそのまま画面に出る
- 名指しできない失敗は、`throw` のまま流す。画面は `error.tsx`、記録は `instrumentation.ts` が受け持つ

## ディレクトリ構成

Root:

```txt
src/
  app/
  components/             # global components
    providers/
      theme-provider.tsx
    ui/                   # shadcn/ui
  config/                 # global config
  features/
  hooks/                  # global hooks
  lib/
  utils/                  # global utils
    cn.ts
    font.ts
    json-ld.ts
    mapping.ts
  instrumentation.ts
  proxy.ts
tests/
```

features:

```txt
src/features/{feature}/
  components/
    providers/{feature}-provider.tsx
  loaders/
  actions/
  hooks/
  services/
  schemas/{feature}.ts
  types/{feature}.ts
  utils/{feature}.ts
  queries/
```

lib:

```txt
src/lib/{api}/
  index.ts

src/lib/supabase/
  admin.ts
  client.ts
  database.ts
  proxy.ts
  server.ts
  types.ts
```
