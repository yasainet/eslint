# プロジェクト アーキテクチャ

## ファイル・フォルダ命名

| 対象       | パス                | 規約                      |
| ---------- | ------------------- | ------------------------- |
| ファイル   | `src/**/*.{ts,tsx}` | `KEBAB_CASE`              |
| フォルダ   | `src/!(app)/**/`    | `KEBAB_CASE`              |
| App Router | `src/app/**/`       | `NEXT_JS_APP_ROUTER_CASE` |

## import

書き方:

| 対象             | パス                                 | 規約                                                     |
| ---------------- | ------------------------------------ | -------------------------------------------------------- |
| import           | `src/**/*.{ts,tsx}`                  | `./` か `@/` で書く。`../` は書けない                    |
| namespace import | `@/features/**` からの `import * as` | 名前は `@/features/` より後ろの path を camelCase にする |

依存方向:

| 層                 | パス                              | import してよい app 内部                                                                |
| ------------------ | --------------------------------- | --------------------------------------------------------------------------------------- |
| lib                | `src/lib/**/*.ts`                 | `./`                                                                                    |
| queries            | `src/features/*/queries/*.ts`     | `@/lib`                                                                                 |
| services           | `src/features/*/services/*.ts`    | `@/features/*/queries`, `@/features/*/schemas`, `@/features/*/types`, `@/utils/mapping` |
| loaders            | `src/features/*/loaders/*.ts`     | `@/features/*/services`                                                                 |
| actions            | `src/features/*/actions/*.ts`     | `@/features/*/services`                                                                 |
| hooks              | `src/features/*/hooks/*.ts`       | `@/features/*/actions`                                                                  |
| feature components | `src/features/*/components/*.tsx` | `@/components`, `@/features/*/hooks`                                                    |
| app                | `src/app/**/*.{ts,tsx}`           | `@/components`, `@/utils`, `@/features/*/components`, `@/features/*/loaders`            |
| schemas            | `src/features/*/schemas/*.ts`     | -                                                                                       |
| types              | `src/features/*/types/*.ts`       | `@/lib/*/types`, `@/utils/mapping`                                                      |

## directive

| 層      | パス                          | 規約                         |
| ------- | ----------------------------- | ---------------------------- |
| actions | `src/features/*/actions/*.ts` | 先頭に `"use server"` が必須 |
| loaders | `src/features/*/loaders/*.ts` | `"use server"` は書けない    |
| hooks   | `src/features/*/hooks/*.ts`   | 先頭に `"use client"` が必須 |

## error

| 対象     | パス                         | 規約                     |
| -------- | ---------------------------- | ------------------------ |
| features | `src/features/**/*.{ts,tsx}` | `try / catch` は書けない |

失敗の扱いは 2 通りだけにする。

- code で名指しできる失敗は、自分で書いた message を `return` する。message はそのまま画面に出る
- 名指しできない失敗は、`throw` のまま流す。画面は `error.tsx`、記録は `instrumentation.ts` が受け持つ

## ディレクトリ構成

Root:

```txt
src/
  app/
  components/             # global components
    providers/
      theme-provider.tsx
    ui/                   # shadcn/ui
  config/                 # global config
  features/
  hooks/                  # global hooks
  lib/
  utils/                  # global utils
    cn.ts
    font.ts
    json-ld.ts
    logger.ts
    mapping.ts
    result.ts
  proxy.ts
tests/
```

features:

```txt
src/features/{feature}/
  components/
  loaders/
  actions/
  hooks/
  services/
  types/{feature}.ts
  utils/{feature}.ts
  queries/
```

lib:

```txt
src/lib/{api}/
  index.ts

src/lib/supabase/
  admin.ts
  client.ts
  database.ts
  proxy.ts
  server.ts
  types.ts
```
