# プロジェクト アーキテクチャ

## ファイル・フォルダ命名

| 対象       | パス                | 規約                      |
| ---------- | ------------------- | ------------------------- |
| ファイル   | `src/**/*.{ts,tsx}` | `KEBAB_CASE`              |
| フォルダ   | `src/!(app)/**/`    | `KEBAB_CASE`              |
| App Router | `src/app/**/`       | `NEXT_JS_APP_ROUTER_CASE` |

## import

書き方:

| 対象   | パス                | 規約                                        |
| ------ | ------------------- | ------------------------------------------- |
| import | `src/**/*.{ts,tsx}` | `./` か `@/` で書く。`../` は書けない       |

依存方向:

| 層  | パス                     | import してよい app 内部 |
| --- | ------------------------ | ------------------------ |
| lib | `src/lib/**/*.{ts,tsx}`  | `@/lib`, `@/utils`       |

## ディレクトリ構成

Root:

```txt
src/
  app/
  components/             # global components
    providers/
      theme-provider.tsx
    ui/                   # shadcn/ui
  config/                 # global config
  features/
  hooks/                  # global hooks
  lib/
  utils/                  # global utils
    cn.ts
    font.ts
    json-ld.ts
    logger.ts
    mapping.ts
    result.ts
  proxy.ts
tests/
```

features:

```txt
src/features/{feature}/
  components/
  entries/
  hooks/
  services/
  types/{feature}.ts
  utils/{feature}.ts
  queries/
```

lib:

```txt
src/lib/{api}/
  index.ts

src/lib/supabase/
  admin.ts
  client.ts
  database.ts
  proxy.ts
  server.ts
  type.ts
```
