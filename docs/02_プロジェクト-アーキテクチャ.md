# プロジェクト アーキテクチャ

## ファイル・フォルダ命名

| 対象       | パス                | 規約                    |
| ---------- | ------------------- | ----------------------- |
| ファイル   | `src/**/*.{ts,tsx}` | kebab-case              |
| フォルダ   | `src/**/`           | kebab-case              |
| App Router | `src/app/**`        | App Router + kebab-case |

App Router の規則: [Project structure and organization](https://nextjs.org/docs/app/getting-started/project-structure)

## ディレクトリ構成

Root:

```txt
src/
  app/
  components/             # global components
    providers/
      theme-provider.tsx
    ui/                   # shadcn/ui
  config/                 # global config
  features/
  hooks/                  # global hooks
  lib/
  utils/                  # global utils
    cn.ts
    font.ts
    json-ld.ts
    logger.ts
    mapping.ts
    result.ts
  proxy.ts
tests/
```

features:

```txt
src/features/{feature}/
  components/
  entries/
  hooks/
  services/
  types/{feature}.ts
  utils/{feature}.ts
  queries/
```

lib:

```txt
src/lib/{api}/
  index.ts

src/lib/supabase/
  admin.ts
  client.ts
  database.ts
  proxy.ts
  server.ts
  type.ts
```
