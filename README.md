# @yasainet/eslint

Shared ESLint configuration for Next.js.

## Entry Points

- `@yasainet/eslint/next` — Common rules + Next.js
  - Feature Root: `src/features/`
  - Entry Points: `src/app/**/*.{ts,tsx}`

## Setup

install / config template は [`docs/setup.md`](./docs/setup.md) を参照。

## Release
